# datalake-sources

Survey three layers: (1) Buzz channel history (last-N scan per channel, hits + nature); (2) project code (CLI spawn sites, endpoint ids, costs); (3) research corpus (docs with endpoint + cost + raw-data pointers).
Keep raw pulls disposable (.scratch/), promote curated to indexed markdown. Channels with zero hits are findings too - record the gap. Source: employmentArc treg/data-lake/SOURCES.md.
